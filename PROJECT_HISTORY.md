## 2. Core Features & Recent Customizations
1. **AI Parser Engines (`parserSettings` in `src/app/page.js`)**
   - **Default Engine**: Groq Cloud (`type: 'grok'`), pre-configured with the user's Groq API key (`gsk_...`) and default vision model `qwen/qwen3.8-27b` (with live model discovery via `GET https://api.groq.com/openai/v1/models`, automatic base64 image compression under 4MB, and automatic Hybrid Tesseract OCR + Groq `llama-3.3-70b-versatile` / `openai/gpt-oss-120b` fallback).
   - **Google Gemini Multi-Model Fallback**: Rotates across `gemini-2.5-flash` -> `gemini-2.5-flash-lite` -> `gemini-2.0-flash` -> `gemini-3.6-flash` when a model returns 503/429 high-demand errors.
   - **OpenAI & Local Regex/Tesseract OCR**: Also supported in the **🤖 Parser AI** tab.
   - Used across all 3 document modules: **Invoice Parser**, **Payment Entry Auto-Check**, and **Quarterly Rebate Reconciliation**.

2. **Camera Photo Capture (`📷 Take Photo`)**
   - Available in both **Invoice Parser** (*Upload Invoice Soft Copy*) and **Payment Entry** (*Auto-check via Payment List Document/Image*).
   - On **mobile/handphone**: Uses `<input type="file" accept="image/*" capture="environment" />` to launch the rear camera directly.
   - On **PC/laptop**: Opens a live webcam modal (`navigator.mediaDevices.getUserMedia`) with **📸 Snap Photo** and **🔄 Switch Camera**.

3. **ERPNext Item Matching & Auto-Creation (`src/app/page.js`)**
   - **Pagination**: Fetches all ERPNext items in batches of 500 (`offset += resIt.data.length`), re-runs item matching reactively via `useEffect([itemsList])`, and performs a direct live ERPNext lookup (`lookupItemsDirectlyInERP`) before declaring an item missing.
   - **Normalized Model Matching (`findMatchingItemCode`)**: Strips parenthetical suffixes like `(O-STD)`, `(C)`, `[STD]` and normalizes dashes/spaces so `DS-PS1-B(O-STD)` matches `DS-PS1-B`.
   - **Auto-Create Missing Items**: Automatically creates missing items in ERPNext before syncing PO/PR/PI, trying item groups `["Product", "product", "Products", "All Item Groups"]` (`is_stock_item: 1`, `stock_uom: "Nos"`).
   - **Audit Comment & Remarks**: Adds `"generated by app"` to `remarks` and posts a comment (`POST /api/resource/Comment`) on every created Purchase Order, Purchase Receipt, and Purchase Invoice.

4. **Payment Entry & Quarterly Rebate Reconciliation**
   - **Payment Entry (`SO` + `ST` Dual Matching)**: Extracts both the Sales Order number (`so_no`, starting with `SO...`) and the Tax Invoice number (`tax_invoice`, starting with `ST...`) from every row of the payment list (supplemented by direct OCR/regex extraction of `SO...`/`ST...` tokens and OCR prefix normalization `5T`/`S7`/`SI` -> `ST`, `5O`/`S0` -> `SO`). Matches each row against ERPNext unpaid invoices (`bill_no`, `name`, `remarks`) by checking `SO` first, then `ST` second, and `SO`↔`ST` prefix counterparts third, while preserving exact payment list row sequence. Handles Credit Notes / Return invoices (negative allocations), and warns on duplicate supplier invoice numbers.
   - **Quarterly Rebate Reconciliation**: Stores rebate records and exception lists in Neon Postgres (`rebate_records` and `rebate_exceptions`), applying 8% (Masterlist DS/iDS/CS), 16% (Non-masterlist DS/iDS/CS), 5% (RG), and 10% (VS) rules.
